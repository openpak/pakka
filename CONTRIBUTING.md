# Contributing

Pakka is in the planning stage. Useful areas include Meta model integration, diagnostic tools, agent collaboration, console interfaces, evaluation and documentation.

Before starting implementation, agree on a bounded task and confirm the hackathon event boundary. Keep pull requests focused and document how behavior was verified. Do not claim a platform works based only on compilation.

Use English for code, identifiers and documentation. Contributions are provided under AGPL-3.0-only. Include attribution for third-party material and publish only material you have rights to share.

Never commit secrets or real player captures. Use synthetic fixtures and document assumptions. Discuss security-sensitive findings privately with the maintainer rather than filing details publicly.
